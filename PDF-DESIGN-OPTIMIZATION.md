## Typography Improvements

### Font Sizes Optimization
**Headers:**
- Company Name: 22pt (was 24pt) - Better proportioned
- ORDER/BILL Split: 26pt/18pt (was 28pt single) - More elegant

**Content:**
- Box Headers: 9pt bold
- Main Text: 9-10pt
- Labels: 8pt
- Footer: 7-9pt
- All optimized for better readability

### Font Weights
- Strategic use of bold vs normal weights
- Better text hierarchy
- Improved visual flow

---

## Spacing & Layout

### Margins & Padding
- Consistent 15px side margins (was 20px)
- Optimized vertical spacing between sections
- Better padding in boxes and tables
- Improved overall document flow

### Box Dimensions
- Info boxes: 88px (Order) and 87px (Customer) width
- Consistent 3px rounded corners
- Optimized heights for content

### Table Dimensions
- Row height: 9px (more compact, professional)
- Header height: 9px
- Better column width distribution
